# Contributing

Thanks for helping improve qbee Game Speed Limiter.

## Development

Build on Windows:

```powershell
.\build.ps1
```

The main app is `QbeeGameSpeedLimiter.cs`. The Python script is kept as a legacy/script-friendly implementation.

## Pull Requests

- Keep changes focused.
- Do not commit personal `qbee_game_speed_limiter.json` files or logs.
- Update `README.md` and `使用说明.md` when behavior changes.
- Include the exact detected process path when reporting false positives.
